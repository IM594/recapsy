# 路线图

[English](roadmap.md) · [简体中文](roadmap.zh-CN.md)

更新于 2026-09-08。1.0 是免费、全本机的桌面应用，云端档在它之后。

## 1.0，免费本机

**记忆**
- 持续截图、本机识字、本机全文搜索，零上传。
- 漏了会知道：每段时间要么有截图，要么有原因。停采自动提醒。
- 保留规则可见可改：删数据的规则摆在明面上。
- 段、日、周三层总结：接任何 OpenAI 兼容地址加 key，Ollama 也走这里。不配就没有，其余功能不受影响。
- 语义搜索：本机向量，可选开关。

**agent 入口**
- 一条命令把 MCP 服务接进 Claude Code、Cursor 或 Codex。
- 每个回答带出处：截图、原文、时间。
- 上下文续接：agent 可问这个人最近在某项目或某目录干到哪了。

**给人看的部分**
- 每日回顾页：今天和本周的时间线、截图、识别文字、段落总结。不做聊天，不做仪表盘。

**信任**
- 不需要账号。
- 一键全量导出，开放格式。
- “什么离开了你的设备”声明页。1.0 的答案只有检查更新时发出的版本号。
- 默认无遥测。

**硬指标**
- 装好到跑起来十分钟内，不需要看教程。
- 活动监视器能耗“低”。风扇不因它转。

**运行要求**
- macOS，需要屏幕录制与辅助功能权限。
- 可选：一个 OpenAI 兼容地址加 key，或本机 Ollama，用于总结。

## 1.0 不做

账号、云端档、手机端、Windows、Linux、聊天界面、浏览器插件、团队版、一次性买断、按用量计费、旧原型的数据迁移。

## 云端档，1.0 之后

托管模型做总结、云端识字、云备份与多设备同步、托管 MCP 让手机上的 agent 也能问、账号与支付。时间取决于需求，等待名单在 [Discussions](https://github.com/IM594/recapsy/discussions)。

## 技术栈

Electron 与 TypeScript 负责主进程与界面。Swift 进程负责采集，含出图前隐私拦截。SQLite 与全文索引。PP-OCR 本机识字。MCP 服务。总结走任何你自配的 OpenAI 兼容模型。
