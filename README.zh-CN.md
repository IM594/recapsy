## 为什么做 Recapsy

开会前十分钟脑袋空空。你让 agent 通过 MCP 问一句“我过去一周做了什么”，三分钟后拿到带细节的发言稿：哪些文件、哪几个对话、哪个下午。没有它，你要提前一小时去翻 git、Slack 和 Notion。

年中总结、年终总结同理。更日常的一幕是 agent 开工前先问“这个人最近在这个项目干到哪了”，自动接上上下文。

Recapsy 不是又一条给人翻的时间线。它的主入口是你已经在跑的 agent：Claude Code、Cursor、Codex，或任何会说 MCP 的东西。

## 它不会骗你

所有录屏工具最终都会默默漏采、默默压缩、默默删。Recapsy 承诺四条底线，竞品没有一个敢承诺。

| # | 底线 | 含义 |
|---|------|------|
| 1 | **漏了会知道** | 每段时间要么有截图，要么记下没截的原因。采集停了会自动发现并提醒你。 |
| 2 | **原图可回看** | 任何时刻的截图和识别出的文字随时可翻，答案可以对质。 |
| 3 | **不会悄悄删** | 删除只按你看得见、改得了的规则执行。 |
| 4 | **答案给出处** | 每个回答附带截图、原文和时间，agent 能原样转述。 |

## 它怎么工作

Recapsy 里的每个想法都先按节奏分类。节奏决定它在哪跑、谁付钱。

| 节奏 | 谁干 | 谁付钱 | 产品含义 |
|------|------|--------|----------|
| **每帧**：截图、识字、索引 | 你的 Mac | 没人，零成本 | 必须本地，零上传 |
| **每天一次**：段、日、周总结 | 你配的模型，或我们托管 | 自带 key 免费；托管收费 | 云端档唯一收费的理由 |
| **随时问**：周报、习惯分析、任何问题 | 你自己的 agent 走 MCP | 你已有的 agent 账单 | 不做聊天界面，官网放 prompt 画廊 |

```
 屏幕 ──▶ Swift 采集 ──▶ PP-OCR（本机）──▶ SQLite + 全文索引 + 向量
                                                  │
                          段 / 日 / 周总结（你配的模型，可选）
                                                  │
                                MCP 服务 ──▶ Claude Code · Cursor · Codex
                                                  │
                                每日回顾页（给人看）
```

识字引擎用 PP-OCR 在本机运行。识字频率、去重和调度的设计目标只有一个：让 OCR 在活动监视器能耗“低”的预算内跑完。风扇因为 Recapsy 转起来，就算 bug。

## 1.0 交付什么

**记忆**
- 持续截图、本机识字、本机全文搜索，零上传。
- 漏了会知道：每段时间要么有截图，要么有原因。停采自动提醒。
- 保留规则可见可改：删数据的规则摆在明面上。
- 段、日、周三层总结：接任何 OpenAI 兼容地址加 key，Ollama 也走这里。不配就没有，其余功能不受影响。
- 语义搜索：本机向量，可选开关。

**agent 入口**
- 一条命令把 MCP 服务接进 Claude Code、Cursor 或 Codex。
- 每个回答带出处：截图、原文、时间。
- 上下文续接：agent 可问“这个人最近在某项目或某目录干到哪了”。

**给人看的部分**
- 每日回顾页：今天和本周的时间线、截图、识别文字、段落总结。不做聊天，不做仪表盘。

**信任**
- 不需要账号。
- 一键全量导出，开放格式。
- “什么离开了你的设备”声明页。1.0 的答案只有检查更新时发出的版本号。
- 默认无遥测。

**硬指标**
- 装好到跑起来十分钟内，不用找作者。
- 活动监视器能耗“低”。风扇不因它转。

## 1.0 不做什么

账号、云端档、手机端、Windows、Linux、聊天界面、浏览器插件、团队版、一次性买断、按用量计费、旧原型的数据迁移。

云端档的开工信号：等待名单到五十人，或有十个人主动问“怎么在两台电脑上用”。没到就不做。

## 运行要求

- macOS。Recapsy 有意只做 macOS，把截图、隐私拦截和本机识字的质量投入集中在一个平台打穿。
- 屏幕录制与辅助功能权限。
- 可选：一个 OpenAI 兼容地址加 key，或本机 Ollama，用于总结。

## 技术栈

Electron 与 TypeScript 负责主进程与界面。Swift 进程负责采集，含出图前隐私拦截。SQLite 与全文索引。PP-OCR 本机识字。MCP 服务。总结走任何你自配的 OpenAI 兼容模型。
