# Recapsy

Give your AI agent a work memory that never lies to you.
给你的 AI agent 装上一份不会骗你的工作记忆。

- The desktop app is free and open source, forever. / 桌面端永远免费、永远开源。
- A cloud tier (multi-device sync, hosted models, backup, ask from your phone) is a subscription that funds this project. / 云端档（多设备同步、托管模型、备份、手机上问）订阅制，用来养这个项目。
- Anything that was free stays free. / 免费过的东西永远免费。

Status: under development, not yet released. / 开发中，尚未发布。

## Origin / 起源

This repository carries the full history of the project since its first commit on 2025-12-10. The tree was cleared on 2026-09-08 to start a local-first rebuild; earlier code remains in the history for reference.
本仓库保留了项目自 2025-12-10 第一个 commit 以来的全部历史。2026-09-08 清空目录树，开始本地优先的重建；之前的代码仍在历史里可查。

- 2025-12 · recaply: generate daily, weekly and yearly work summaries from git history / 从 git 记录生成日报、周报、年终总结
- 2025-12 · first Electron desktop attempt / 第一次桌面端尝试
- 2026-01 · recapsense: screen → OCR → search → MCP, the first local memory pipeline / 第一条本地记忆管线
- 2026-02 · native Swift experiment / Swift 原生尝试
- 2026-04 · TypeScript monorepo architecture draft / monorepo 架构稿
- 2026-05 · Recapsy monorepo, Swift capture engine with pre-capture privacy interception / 含出图前隐私拦截的 Swift 采集引擎
- 2026-09 · local-first rebuild begins / 本地优先重建开始
